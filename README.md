# XPixiv

Pixiv + X（Twitter）+ Fanbox 三平台图片浏览器桌面应用。下载、整理、打标、训练集导出一站式完成。

> 最新版本 exe 见 [Releases](../../releases)，下载后直接运行，无需安装。

---

## 功能总览

### 🖼 三平台浏览

- **Pixiv**：推荐流/搜索/作者页瀑布流，作品查看器（多图/动图/收藏/相关作品），标签中文翻译
- **X（Twitter）**：推荐流（为你推荐/关注）、搜索四档（热门/最新/媒体/用户）、用户页三档（媒体/帖子/回复）、推文评论区、趋势栏——全部内置直连引擎，不依赖浏览器
- **Fanbox**：创作者投稿浏览与下载
- **跨平台互跳**：三平台用户主页互相识别跳转（X 简介里的 Pixiv 链接一键直达，带平台图标提示）
- 内置浏览器标签页：需要时可在应用内打开真实网页（X 官网等）

### ⬇️ 下载

- **批量下载**：粘贴任一平台作者主页链接 → 自动跳转并展开批量面板；方向（新→旧/旧→新）、日期范围、数量上限（-1 = 全部）、截止点自由控制
- **下载页**（侧栏「下载」）：批量任务创建与任务管理、下载列表、批量条目打包折叠显示、活跃任务徽标
- **重复检测**：已下载过的自动跳过，不重复下载
- **队列管理**：批量任务串行执行防限流，暂停/恢复/取消随时可控
- **剪贴板**：全 Rust 实现，复制图片/链接零系统权限弹窗；X 卡片复制有进度反馈（转圈→对勾）
- 下载文件按模板命名（作者/日期/作品ID 自动组织）

### 🗂 图库（本地素材管理）

- 三层结构：作者列表 → 组内网格 → 大图查看器（裁剪/去背景/去水印等编辑工具）
- **单击看详情 / 双击开大图**：右侧详情侧栏显示元数据+标签编辑器
- **隐藏与归档**：图片级隐藏（置底弱化）、整组归档（训练完的作者收进归档区），两层独立互不干扰
- **多选**：Ctrl 点选 / Shift 连选，批量隐藏、恢复、移动到其他组
- **分组**：作者组内建概念分组（名称+轮次），每组可设训练参数
- **缩略图**：视频自动生成缩略图（与图片同样浏览）
- **卡片尺寸**：设置里宽高独立调节（自定义比例），等比完整显示不变形
- **导入**：拖拽 zip/文件夹到图库页即可导入外部素材；图包自带的打标 txt 自动入库
- **导出**：普通打包（zip/文件夹）或训练集模式（见下）；轮次空=平铺，填了=按概念文件夹组织

### 🏷 打标器与训练素材中台

- **单图打标**：WD14 系列 ONNX 模型本地推理（DirectML GPU 加速），双模型可选（wd-vit-v3 快速档 / wd-swinv2 精度档）
- **批量打标**：图库里多选/整组/整作者触发，后台队列（暂停/续跑/取消/断点续跑）
  - 置信度权重变换：自由公式（如 `c*0.8+0.1`，支持 min/max/clamp/幂运算）
  - 前置词（触发词置首）/ 筛选黑名单（词典联想输入，全半角逗号自动分词，空格/下划线归一）
- **标签编辑**：批量增/删/替换（正则支持），应用前红绿 diff 预览；单图快编弹层
- **内置中英 tag 词典**（4.7 万条）：联想显示「英文 中文」，支持别名命中
- **训练集导出**（kohya_ss 格式）：`img/<轮次>_<概念名>/图片+同名caption.txt`，可选附带 dataset config.toml；触发词自动前置，未打标图跳过统计

### 🔄 其他

- **自动更新**：启动自检（可关），标题栏更新徽标，一键下载安装（sha256 校验+热替换）
- **R-18 过滤**：全局+页面级三态控制
- **屏蔽**：标签/作者屏蔽过滤
- **代理**：系统代理/TUN 自适应，下载浏览全走代理链路
- 深色/浅色主题

## 快速上手

1. 从 [Releases](../../releases) 下载最新 `XPixiv-vX.Y.Z.exe`
2. 双击运行（便携版，无安装）
3. 首次使用：到 **设置 → 账号与平台** 登录 Pixiv / X / Fanbox
4. 下载：任意平台作者页 → 「批量下载」按钮
5. 训练流：下载 → 图库整理/分组 → 批量打标 → 导出训练集

## 系统要求

- Windows 10/11 x64
- 无需其他依赖（打标模型首次使用时自动下载）
